# 출석핑 (Ping)

> **비컨이 "핑" 신호를 쏘면 자동 출석.** 교사 폰·교실 태블릿이 곧 출석기 — 비컨 하드웨어 없이, 나이스 이관까지 한 번에.

이름 그대로, 교실의 기기가 *핑* 하고 신호를 보내면 학생은 앉아 있기만 해도 출석돼요.

---

## 무엇인가

개별 교사가 관리자·MDM 없이 **5분 안에** 도입하는 출결 앱. 교실에 둔 갤럭시탭(또는 교사 폰)이 BLE 비컨이 되어 학생을 자동 출석시키고, 폰이 없거나 수거하는 학교는 키오스크 QR/PIN으로 대응합니다. 결과는 **나이스(NEIS)로 옮기기 쉽게** 정리됩니다.

## 핵심 기능 (v1)
- **BLE 근접 자동 출석** (Android 우선, 아이폰은 포그라운드 원탭) — 핵심 차별점, 이름의 유래("핑")
- **키오스크**(갤럭시탭): 회전 QR(5초) + PIN/명단 체크인 + 화면 고정
- **학생앱**(Android/iOS): QR 스캔 + BLE 감지
- **교사 대시보드**: 세션 시작/중단, 실시간 현황, 수동 수정
- **교시별 + 조회 출결** (세션 단위), 상태 5종(출석/지각/조퇴/결과/결석) + 사유 4종(출석인정/질병/미인정/기타)
- **나이스 예외만 내보내기** (클립보드 TSV / 엑셀 / PDF)
- **개인정보 최소화**: 좌표 미저장, 미성년자 보호자 동의 확인

## 기술 스택
- **앱**: Flutter (Android + iOS 네이티브)
- **백엔드**: Supabase (Auth / DB / Realtime / RLS / Edge Functions)
- **BLE**: `dchs_flutter_beacon`(감지 — iPhone iBeacon은 CoreLocation ranging 필수) + `beacon_broadcast`(키오스크 비컨, 고정 UUID + 회전 minor)
- **레퍼런스**: banha (출결 컨셉·검증 로직 이식 원본)
