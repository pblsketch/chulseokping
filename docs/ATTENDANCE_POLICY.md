# 출석핑 — 출결 처리 지침 (2026 기준)

> **목적:** 출석핑의 출결 상태/사유 enum, 나이스(NEIS) 이관·내보내기 로직이 **국가 출결 지침과 1:1로 정합**하도록 보장하는 도메인 레퍼런스. 코드(특히 데이터 모델·Edge Function·내보내기)는 이 문서를 근거로 한다.
>
> **정본 출처 (2026):**
> - 「학교생활기록 작성 및 관리지침」 **[시행 2026. 3. 1.] [교육부훈령 제555호, 2026. 2. 12. 일부개정]**
> - 동 지침 **[별표 8] 출결상황 관리 등** (국가법령정보센터)
> - 2026학년도 학교생활기록부 기재요령(시도교육청)
>
> ⚠ **면책/주의:** 경조사 일수·증빙·환산 등 **세부는 시도교육청·학칙으로 보강·상이**할 수 있다. 실데이터 운영 전 (a) 최신 훈령/기재요령 재확인, (b) 대상 학교 학업성적관리규정 확인이 필요하다. 본 문서는 개발 기준이며 법적 자문을 대체하지 않는다.

---

## 1. 출결 상황 구분 (5종)

| 구분 | 정의 |
|---|---|
| **출석** | 출석해야 할 날 정상 출석 |
| **결석** | 출석해야 할 날 출석하지 않음(당일 미등교) |
| **지각** | 학교장이 정한 **등교시각까지** 출석하지 않음(등교는 함) |
| **조퇴** | 등교시각과 하교시각 **사이에 하교** |
| **결과(缺課)** | **수업시간의 일부 또는 전부에 불참**(등교는 함). = 교시 단위 결손 |

- **결석 vs 결과:** 결석=당일 미등교(일 단위), 결과=등교했으나 특정 **교시** 불참(교시 단위). → 출석핑이 **교시별 출결(PERIOD 세션)**을 지원해야 결과를 정확히 담는다.
- **같은 날 중복:** 같은 날 지각·조퇴·결과가 동시 발생하면 **학교장 판단으로 한 가지로만 처리**. → 앱은 일(HOMEROOM) 세션에서 하루 1건으로 수렴(PRD 멱등), 교시(PERIOD)는 교시별 1건.

## 2. 사유 분류 (4종) — 상태와 직교(2축 모델)

각 비출석 사건(결석/지각/조퇴/결과)에 **사유**를 부여한다.

| 사유 | 의미 | NEIS 집계 |
|---|---|---|
| **출석인정** | 부득이/공적 사유로 **출석으로 처리** | **출석으로 인정**(결석/지각/조퇴/결과 칸에 **미집계**) |
| **질병** | 질병·부상 | 질병 칸 집계 |
| **미인정** | 정당한 사유 없이/고의(무단) | 미인정 칸 집계 (입시 감점·징계 사유) |
| **기타** | 위 어디에도 안 드는 부득이한 사유 | 기타 칸 집계 |

> **핵심:** NEIS 출결상황 표의 칸은 결석/지각/조퇴/결과 각각 **질병·미인정·기타 3종**뿐이다. **출석인정은 별도 칸이 아니라 "출석" 처리**다. 따라서 **데이터 모델은 (상태) × (사유 4종)** 2축으로 잡고, 내보내기에서 출석인정을 출석으로 취급한다.

## 3. 출석으로 인정하는 결석(출석인정) 사유

별표 8 기준 대표 사유:
- **경조사** (아래 §4 일수 표)
- **법정감염병**으로 인한 등교중지, **천재지변**(지진·폭우·폭설·해일 등)
- **학교장이 허가한 교외체험학습** (단, §5 — **학생부에 미입력**)
- 학교폭력 피해로 인한 결석(인과관계 증명 시) 등 지침이 정한 사유
- 기타 부득이하다고 학교장이 인정한 출석인정 사유

## 4. 경조사별 출석인정 일수 (주5일 수업 기준, 별표 8)

| 대상 | 일수 |
|---|---|
| 부모, 조부모, 외조부모 (사망) | **5일** |
| 증조부모·외증조부모, 형제자매 및 그 배우자 (사망) | **3일** |
| 부모의 형제자매 및 그 배우자 (사망) | **1일** |
| **본인 결혼** | **1일** |

**처리 원칙:**
- 사유 발생일을 **포함하여 전후**에 실시함이 원칙. **단, 사망은 발생일 미포함, 그 다음 날부터** 처리 가능.
- 일수 산정 시 **토요일·공휴일·재량휴업일 미산입**.
- 해당 기간 내 학생은 상황에 따라 출석 가능(전부 결석할 필요 없음).
- 증빙: 사망/결혼 등 사실 확인 서류(가족관계증명서 등).

## 5. 학교장 허가 교외체험학습

- 학교장 허가 운영은 유지되며 **출석으로 인정**.
- **2024학년도부터 학교생활기록부(출결 특기사항)에는 입력하지 않음.** → 앱은 교외체험학습을 **출석인정으로 처리하되 NEIS 출결 특기 미기재** 대상으로 분리 관리(학교 자체 신청/정산용으로만).

## 6. 질병결석 증빙

- 결석한 **날부터 5일 이내**에 **의사의 진단서 또는 의견서**를 첨부한 **결석계**를 제출 → **학교장 승인**.
- 미제출/미승인 시 **미인정**으로 처리될 수 있음.
- → 앱 모델에 `document_submitted`(증빙 제출 여부) + 제출기한 알림(D+5) 반영 권장.

## 7. 개근

- 해당 학년 동안 **결석·지각·조퇴·결과가 1회도 없으면** 특기사항에 **'개근'** 입력.
- **출석인정만 있는 경우는 개근 인정**(출석으로 처리되므로).

## 8. 2026학년도 변경점(반영)

- 출결 **특기사항 입력 범위 완화**: 장기결석/단기결석 특기사항 기재를 **별도로 제시하지 않음**(2026 기재요령). → 앱의 특기사항 입력 UI는 강제 분류를 줄이고 자유 입력 + 권고만.
- (지속) 교외체험학습 학생부 미입력, 의견서 증빙 인정.

## 9. ⚠ 자동 환산 주의 (미인정 지각 3회 = 결석 1회?)

- "미인정 지각/조퇴/결과 3회 = 미인정 결석 1일" 식 환산은 **국가 NEIS 집계 규칙이 아님.** 주로 **학교 내신 산정·생활규정** 차원이거나 학업성적관리규정에 따른다.
- → 앱은 **NEIS 집계는 환산하지 않고** 지각/조퇴/결과를 그대로 집계. 환산이 필요한 학교용 통계는 **별도 부가 기능(옵션)**으로만, 기본 미적용.

## 10. 앱 매핑 규칙 (출석핑 구현 계약)

### 10.1 데이터 모델 (2축)
- **상태(status):** `출석(present)` / `결석(absent)` / `지각(late)` / `조퇴(earlyLeave)` / `결과(classAbsent)`
- **사유(reason):** `출석인정(recognized)` / `질병(sick)` / `미인정(unrecognized)` / `기타(other)`
- 출석인정 사유는 추가로 **세부 코드** 보유 권장: `경조사 / 법정감염병 / 천재지변 / 교외체험학습 / 학폭피해 / 기타인정`.
- 교외체험학습 플래그: `neisExcluded = true`(§5, 출결 특기 미기재).

### 10.2 나이스 "예외만 내보내기" 규칙 (PRD §6 정밀화)
> ❗ **중요 수정:** 기존 PRD는 "status ≠ 출석"으로 예외를 뽑았으나, **정확한 규칙은 사유 기준**이다.
- **NEIS 칸 집계 대상(=내보내기 포함):** 사유 ∈ {**질병, 미인정, 기타**} 인 결석/지각/조퇴/결과.
- **출석으로 처리(=집계 제외):** 사유 = **출석인정** (경조사·감염병·천재지변·학폭피해). → 결석/지각/조퇴/결과 칸에 넣지 않음.
- **교외체험학습:** 출석인정이면서 **학생부 미기재** → NEIS 출결 내보내기에서 제외(별도 목록).
- 내보내기 행 컬럼: 학번·이름·날짜·교시(조회=일과)·상태·사유(질병/미인정/기타)·세부사유·증빙제출.

### 10.3 세션 단위 매핑
- **HOMEROOM(조회) 세션** → NEIS **일 단위 출결**(결석/지각/조퇴).
- **PERIOD(교시) 세션** → NEIS **결과(교시 결손)**.
- 같은 날 지각·조퇴·결과 중복 → 일 세션은 1건으로 수렴(교사가 한 가지 선택).

### 10.4 회귀 가드(테스트로 고정)
- "사유=출석인정인 사건은 NEIS 예외 내보내기에 **포함되지 않는다**."
- "교외체험학습은 NEIS 출결 내보내기에서 **제외된다**."
- "개근 판정 시 출석인정만 있는 학생은 **개근**으로 본다."
- "지각/조퇴/결과를 결석으로 **자동 환산하지 않는다**."
