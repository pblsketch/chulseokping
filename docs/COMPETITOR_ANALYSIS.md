## 1. 앱별 기술 프로필

### 1-1. 공주대학교 전자출결 (xidsystem = ㈜씨드시스템)

| 항목 | 내용 |
|---|---|
| 패키지 | Android `com.knu.knu_abookn` / iOS `com.xidsys.knuabookstore` |
| 평점·규모 | **2.14★** (99개 평가), 설치 10,000+, 2017 출시, 2025-12 최종 업데이트 (`out_knu.txt`) |
| 개발사 | ㈜씨드시스템(부산) — https://xidsys.co.kr/ , 화이트라벨 `*_abookn` 제품군(경상국립대 `com.gnu.gnu_abookn` 등) |

**출석 확인 메커니즘 — "폰투폰(P2P) 블루투스", 고정 비컨 아님** (근거: `kongju_manual.pdf`, https://xidsys.co.kr/smart-check)

- **BLE 송신원 = 사실상 학생 폰 (교수 폰이 스캔 앵커)**: 교수 앱 [출석체크 시작] → 서버가 수강생 전원에 PUSH → **30~40초간 교수 폰과 학생 폰이 블루투스로 직접 통신**해 근접 확인 → 교수 화면에 40초 카운트다운 + 출석/결석 실시간 집계 → 미출석자 수동 터치 정정 → [출석처리마감] 시 서버 저장. 재실행 시 **결석자에게만** 재PUSH(부분 재시도).
- **클래식 BT 기기검색(inquiry) 기반 증거**: iOS 학생은 **기기 이름을 학번으로 변경** 필수, 문제 시 **BT MAC 주소를 수동 복사해 앱에 입력**(매뉴얼 4~5쪽). Android 리뷰 "앱 켤 때마다 기기 이름이 자동으로 학번으로 바뀌네요"(2020-02) — 앱이 기기명 강제 변경. 교수에게 "정확도 위해 **Wi-Fi OFF** 권장"(2.4GHz 간섭 회피).
- **대형 강의(채플 500명+)용 하드웨어 비컨 모드 병행**: 학생이 수업 5분 전~시작 10분 내 [출석체크] 버튼 → 출석, 10~30분 → 지각 자동 처리. 교수 체크 후 늦게 온 결석자가 셀프 체크하면 자동 지각 처리(매뉴얼 10~11쪽).
- QR 회전 언급: 씨드시스템은 "실시간 변경되는 QR코드·인증번호" + 비컨/NFC + P2P의 "고도화된 복합 인증"을 광고(회전 주기 비공개) — https://xidsys.co.kr/smart-check

**Android 권한** (`out_knu.txt`): 정확한/대략적 위치(GPS), 블루투스 페어링·설정 접근, Wi-Fi 연결 보기, NFC 제어, 카메라, 저장소 R/W, **실행 중인 앱 검색**, 시작 시 자동 실행, 절전 방지, 스티키 브로드캐스트 → 구형 SDK 스타일 과다 권한.

### 1-2. 스마트 체크인 (오투오메이트 / O2OMATE)

| 항목 | 내용 |
|---|---|
| 패키지 | Android/iOS `com.kinderkiosk.parent` (패키지명이 정체 노출: 유치원 키오스크) |
| 규모 | Android 2026-01 출시, 설치 100+, v1.0.9. 개발사는 앱 2개뿐인 초기 스타트업(iTunes artistId 1705580723, 다른 앱은 주짓수 리그 앱 `com.o2omate.divisionApp`) |

**출석 확인 메커니즘 — 고정 태블릿/키오스크 + QR. BLE·GPS 없음** (근거: `out_others.txt` Play 설명 전문, iTunes API):

- 시설 고정 태블릿·키오스크에서 **QR 스캔 또는 화면 터치 입력**으로 체크인, 서버(API) 실시간 연동 + 웹 관리자/백오피스 연계
- 무인 운영: 자동 초기화, 연속 체크인, 안내 화면 겸용
- 학부모 앱 기능(iOS 릴리스 노트): **"대리인 하원 부탁하기"**(지정 대리인 픽업 위임), 유치원 공지, 자동로그인 토큰 14→30일 — 스크린샷의 "일회용 QR/예약"은 **하원 위임용 1회성 QR** 흐름으로 추정. QR 회전 주기는 비공개.
- "서비스 제공 목적 외 어떠한 정보도 수집·저장하지 않습니다"라고 개인정보 최소화 명시

**Android 권한** (`out_others.txt`): 카메라(QR), 마이크·오디오 설정(안내음), 저장소, **다른 앱 위에 그리기**(키오스크 고정), 절전 방지, 네트워크, Google Play 라이선스. **위치·블루투스 권한 전무** — 등하원 시나리오에서 QR+키오스크만으로 권한 최소화가 가능함을 보여주는 사례.

**리뷰의 기술적 불만** (전체 1건, 1★, 2026-03, `out_others.txt`):
> "인증문자도 안 오고… 내 QR을 찍는 것/유치원 QR을 찍는 것을 왜 날씨(아이콘)로 고르는지 이해 안 되는 UX. 베타테스터가 된 기분"

→ SMS 인증 발송 실패(온보딩 이탈), **"내 QR 제시" vs "시설 QR 스캔" 양방향 모드 구분 불명확**이 UX 난제.

**운영 자동화**: 자동 종료(일정 시간만 체크 창), 반복 체크(정해진 시간마다), 예약 시작(특정 시각 자동 개시), 진행 푸시, 내역 조회.

**부정 출석 감지 3종**(설명 명시): ① 대리출결 감지(한 폰으로 2명+ 체크) ② 거리체크 감지(비정상 원거리 체크) ③ 기기변경 감지(다른 기기 체크 = 기기 바인딩).

**Android 권한** (`out_others.txt`): 정확한/대략적 위치, 카메라, 블루투스 페어링·설정, Wi-Fi 정보, 시작 시 실행, 절전 방지. (BT 권한은 있으나 주 인증은 GPS.)

## 2. 대리출석(부정 출석) 방지 기법 정리

**확인된 공격 수법** (연세춘추 http://chunchu.yonsei.ac.kr/news/articleView.html?idxno=22367 , 한국경제 https://plus.hankyung.com/apps/newsinside.view?aid=201907011173A):
1. **강의실 밖 인증**: 비컨 신호가 복도로 새어 문 앞 출석 후 이탈 — 도달 거리 튜닝 실패가 구조적 원인
2. **인증번호 단톡방 공유**: 교수 발행 고정 번호를 채팅방에 올려 원격 입력
3. **계정 공유 대리출석**: 포털 ID/PW를 친구에게 줘 대신 앱 출석 (기기 바인딩 부재)
4. **이의신청 악용**: "시스템 오류였다"며 사후 출석 인정받기
5. 학교 대응 현실: "인증번호 입력 시간 단축" 수준. 단말기 교체·위치기술 도입은 "재정 부담"으로 보류

## 3. 출석핑 적용 개선 아이디어 (우선순위 목록)

전제: 출석핑 = 교사 태블릿이 BLE 비컨 광고(송신원) + 회전 QR 5초 + BLE minor TOTP 회전. 경쟁 제품 실패는 모두 **"감지 실패 → 침묵 → 학생 불이익 → 교사에게 수동 정정 요청"** 루프에 수렴.

| # | 아이디어 | 근거 |
|---|---|---|
| 1 | **수동 정정을 1급 시민으로**: 교사 태블릿에서 미출석자 원탭 정정 + 정정 사유 자동 기록 + "감지 실패 vs 실제 결석" 구분 통계. KNU의 "이름 터치 → 마감 → 서버 저장" 흐름 참고 | `out_knu.txt`·`out_ucheck.txt` 최다 불만, `kongju_manual.pdf` 6쪽 |
| 2 | **결석자 한정 재시도**: 재체크 시 기출석자는 불변, 미감지자만 재스캔·재알림 (BLE 안정 판정에 "부분 재시도" 개념) | `kongju_manual.pdf` 6쪽 |
| 3 | **BLE→QR→교사 수동 3단 폴백을 한 세션 안에서**: 단일 수단 시스템은 전부 2점대. U-Check 4모드·씨드시스템 복합 인증이 업계 표준 | `sitin.html`, xidsys.co.kr/smart-check |
| 4 | **블루투스 몰래/강제 켜기 금지 + 세션 스코프 스캔**: OS 표준 다이얼로그만 사용, 수업 세션 중에만 스캔. "시간표 연동 자동 on/off" 요청이 2017년부터 미충족 → 출석핑 설계(세션 중에만)가 그대로 차별점 | `out_knu.txt` 최다 불만 |
| 5 | **감지 상태 실시간 가시화 + 실패 이유 노출**: 학생 화면에 "비컨 감지됨/약함/없음, 서버 전송 중/완료" 단계 표시. 침묵하는 실패가 최악의 UX | `out_ucheck.txt` "왜 혼자만 네트워크 안 좋다는지" |
| 6 | **기기 바인딩**: 계정당 기기 1대 + 기기변경 시 재인증 + 한 기기 복수 학생 체크 감지. 거리 검증은 GPS가 아닌 **근접 boolean**으로(좌표 금지 원칙 유지) | 연세춘추 계정 공유 사례, `out_others.txt` YunLabs 3종 감지 |
| 7 | **신호 도달 거리 튜닝을 운영 기능으로**: 교사 설정에 Tx 파워/RSSI 임계 프리셋(소형 교실/강당), "옆 반 신호 잡힘"을 설치 후에도 조정 | 연세춘추 "강의실 밖 인증" 허점 |
| 8 | **회전 주기 우위 유지 + 1회성 소비**: 고정 인증번호는 반드시 단톡방으로 뚫림. 출석핑의 QR 5초·minor TOTP 회전은 공유·전달 시간보다 짧아 구조적 우위 — 서버에서 토큰 1회성 소비(재사용 거부)까지 강제 | 연세춘추 인증번호 공유 사례 |
| 9 | **출석 스파이크 부하 설계**: 수업 시작 시각 동시 제출 폭주. Edge Function 쓰기에 멱등키 + 지수 백오프 재시도 큐 | `out_knu.txt` "많아지면 먹통", `out_ucheck.txt` "서버 터짐" |
| 10 | **권한 최소화 + 요청 전 이유 설명**: 실행 앱 조회·NFC 등 불요 권한 배제, BLE 위치 권한 게이트(기구현) 방향 유지. 스마트 체크인의 무위치·무BT 사례가 벤치마크 | `out_knu.txt` 권한 루프 불만, `out_others.txt` |
| 11 | **셀프 진단 화면("왜 출석이 안 됐나요?")**: 실패 로그 기반 자가 진단으로 문의 자체를 감소. xidsystem 답변 0건·U-Check 복붙 답변이 별점을 더 깎음 | `out_knu.txt`, `out_ucheck.txt` |
| 12 | **K-12 특화**: 등하원 안전(대리인 하원 위임 1회성 QR 유형) 벤치마크, 담임 확인→학부모 알림 지연을 KPI로. 위치 데이터를 광고에 쓰는 모델(YunLabs)이 실존 → "좌표 무수집"을 마케팅 최전면에 | `out_others.txt` |
