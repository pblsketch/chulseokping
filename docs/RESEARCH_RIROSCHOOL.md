### 출결 모듈의 구체 동작 — 3가지 방식 + 하드웨어
1. **교문 등교 체크**: 학교 출입구에 설치된 **"리로 스캐너"** + **"스마트 학생증"**(RFID/NFC 내장, #Tagless #ACC센서 #Auto Sleep)으로 자동 등교 체크. 같은 학생증으로 **급식 인원 체크, 기숙사 출입 관리**까지
2. **수업 출석**: **교사용 앱에서 원클릭 출석 체크**(교사가 스마트학생증 일괄 탐색 → 감지된 학생 확인). 학생 자가 체크가 아니라 교사 주도
3. **스마트 출결 서비스(자습·공간 한정)**: **"비콘 설치 하나로 학생들의 셀프 입실/퇴실 체크"** — 학생이 앱으로 입실/퇴실 버튼, 교사는 실시간 현황 확인. 자기주도학습(야자) 출결용
4. **앱 권한 (Google Play 고지 원문)**: "필수 허용 권한: 없음. 선택 허용 권한: … **위치: 출결 서비스 위치 확인 시 사용** / **블루투스·근처 기기: 비콘 탐색 후 출결 서비스 출석 체크 시 사용**" — 즉 **리로스쿨도 BLE 비콘 + 위치 권한 기반 출결을 이미 운영 중**
- 결석·지각 등 **NEIS 공식 출결부와의 자동 연동 근거는 없음**(결재 완료된 신고서를 교사가 NEIS에 옮기는 구조로 추정). 리로스쿨 출결은 학교 내부 관리용

## 2. 가격 / 영업 모델

- **학교(기관) 단위 연간 계약 + 학생·학부모는 무료**. "학교 차원에서 유료로 구독료를 지불하고 소속 학생·학부모는 무료로 앱 활용" (https://edu.dasfl.com/entry/리로스쿨-진로진학관리-앱 )
- **가격 앵커: "학교당 계약금이 연 300만원 상당"** (나무위키, 2020년 판 — 학생들이 서버 품질 비판 맥락에서 언급). 공식 가격표는 비공개, "도입문의 1644-9325" 영업
- **부가서비스 업셀 구조**: 정규시간표 편성(※부가서비스 표기), 스마트 학생증(하드웨어), 리로 스캐너, 비콘 출결, 학력평가 문항분석 등은 기본 계약 외 추가 과금으로 추정
- B2C 병행: 리로클라우드(학생 개인 유료), 구독멤버십+(프리미엄 생기부 관리 — riroschool.kr/mentor/intro)
- **조달 경로**: 나라장터·벤처나라·디지털서비스몰에서 "리로소프트" 등록을 검색상 확인하지 못함. 연 300만 원 수준이면 **학교장터(S2B) 수의계약 또는 학교 자체 수의계약**으로 학교회계(자체 예산)에서 집행하는 전형적 패턴. 사립고 중심으로 시작 → "2018년 이후 교육부에서도 공립고에 이용 권고"(나무위키) → 국공립 확산
- **도입 현황**: 2021년 500여 개교(아이티센 투자 보도) → **2025년 1,000개+ 학교, 교사 8만+, 학부모 가입률 93.8%**(2024.2, 회사 발표). 지역 분포: 서울 186, 경기 134, 경북 87 (회사 페이지). 시장점유율 "관련 분야 1위" 주장
- 매출 추정: 1,000개교 × 연 300만~수백만 원 + 부가서비스/하드웨어 = **연 30억~수십억 원 규모** (비상장·DART 미공시로 정확 수치 확인 불가. "매년 100%+ 성장, 두 자릿수 영업이익률" — 채용 플랫폼 소개 문구)

## (b) 출석핑 관점 시사점

### 리로스쿨이 이미 하고 있는 것 (과대평가 금지)
1. **BLE 비콘 출결은 이미 존재** — "비콘 설치 하나로 셀프 입실/퇴실"(스마트 출결 서비스). 단, **자습(야자)·한정 공간용 부가서비스**이고, 정규 수업 출결의 기본형은 여전히 교사 원클릭 + 교문 스캐너
2. 하드웨어 풀스택: RFID/NFC 스마트 학생증 + 교문 스캐너 + 비콘 → 등교·급식·기숙사까지 커버
3. 결석/체험학습 4단계 전자결재(학생→학부모 서명→담임→부장) — 출결 '서류' 프로세스 디지털화는 완성형
4. 교사 온보딩(방문/화상 연수), 학교당 연 단위 B2B 과금, 교육청 권고 확보 — 영업 플레이북이 성숙

### 리로스쿨이 안 하는 것 / 못 하는 것 = 출석핑의 공간
1. **하드웨어 없는 자동 출석**: 리로는 학생증(구매 필요)·스캐너(설치 공사)·비콘(부가 계약)에 의존. 출석핑의 "교사 폰이 비콘, 학생 폰이 감지기(또는 역방향)" 모델은 **하드웨어 0원**이라는 도입 장벽 차이를 만들 수 있음
2. **프라이버시 최소화가 정확히 리로의 약점을 찌름**:
   - 리로: 위치 권한 사용(출결 위치 확인) + 처리방침에 위치정보 미기재 + Play 데이터 보안 "수집 없음" 허위성 선언 + 학교 위탁 구조 불투명 + 학생 대상 앱 내 광고
   - 출석핑: **좌표 미수집(근접 boolean + 회전 minor만), 동의 서버 강제, PII 최소화**를 공개 문서로 명문화하면 "리로 대비 검증 가능한 프라이버시"가 영업 문구가 됨. 실제로 "개인정보 우려로 리로스쿨을 끊는 공립고"가 생기는 중 — 이탈 수요가 존재
3. **초등 시장 공백**: 리로는 중·고 학사(생기부·입시) 중심. K-12 전체, 특히 초·중 출결에는 실질 경쟁자가 아님
4. **학생 UX**: 리로의 구조적 약점(구매자=교사, 사용자=학생)이 10년째 리뷰에 누적. 학생·학부모가 좋아하는 출결 경험 자체가 차별점
5. **단일 목적 vs 올인원**: 리로와 기능 폭으로 경쟁하면 짐. 출결 한 축(자동·정확·프라이버시)의 깊이로 승부하고, 리로가 못 하는 "정규 수업 자동 출석"을 핵심 데모로

### 유료 모델 벤치마크
- **학교당 연 300만 원 내외**(2020 기준, 현재는 상향 추정)가 시장이 수용하는 가격대. 학생·학부모 무료는 사실상 표준
- 기본 구독 + 부가서비스(하드웨어·고급 기능) 업셀 구조, S2B/수의계약 경로, 사립고 선공략 → 교육청 권고 확보 순서는 그대로 참고할 것
- 출석핑 가격 설계 시: 하드웨어 없는 만큼 리로 '스마트 출결 부가서비스'보다 저렴한 진입가(예: 학급/학교 규모별 연 구독)로 포지셔닝 가능

### 개인정보 처리방침에서 배울 점 / 피할 점
- 배울 것: 수탁사 실명 공개(페이레터·LG U+·비즈뿌리오·AWS), 보유기간·법정근거 표, 책임자 실명·연락처 — 형식은 갖춤
- 피할 것(우리는 반대로): ① 학교(개인정보처리자)↔업체(수탁자) 관계·데이터 소유를 방침에 명시하지 않는 것 ② 앱 권한(위치)과 방침 수집항목의 불일치 ③ 스토어 데이터 보안 선언과 실태의 괴리 ④ 14세 미만 동의를 약관 한 줄로 때우는 것(출석핑은 동의 흐름을 서버가 강제 + 증빙 보관) ⑤ 미성년자 필수 앱에 광고 게재
