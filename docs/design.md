# 출석핑 — 디자인 시스템 (design.md)

> 톤: **밝고 미니멀, 도구형.** 교사의 신뢰·가독성이 최우선. 장식 최소, 정보는 명료하게. 학생 친화 플레이풀 요소(밈·보상)는 **v2**에서 학생 화면에만 얹는다.

## 0. 3 surface, 한 가지 언어
학생앱 · 키오스크 · 교사 대시보드는 **동일 토큰(컬러·타이포·스페이싱·상태색)** 을 공유한다. 차이는 *밀도와 크기*뿐:
- **학생앱**: 단순·큰 액션 1개("출석!"), 결과 즉각 피드백.
- **키오스크**: 원거리 가독(특대 폰트·고대비), 단일 동작(스캔/PIN), 오조작 방지.
- **교사 대시보드**: 정보 밀도 높음, 표·필터·실시간.

## 1. 컬러 토큰

라이트/뉴트럴 베이스. 브랜드 컬러는 "핑"의 경쾌함을 담되 **차분하게**(유치하지 않게).

```
// Brand
brand/primary      #2E6BE6   // 신호·핑 블루 (CTA, 활성)
brand/primaryHover  #1F57C2
brand/accent       #18B6A6   // 보조 강조(성공 근처 톤)

// Neutral (밝은 베이스)
bg/base            #FFFFFF
bg/subtle          #F6F8FB   // 카드/섹션 배경
bg/elevated        #FFFFFF
border/default     #E4E8EF
text/primary       #1A1F29
text/secondary     #5B6472
text/disabled      #9AA3B2

// 출결 상태색 (색맹 안전 + 항상 텍스트 라벨 병기)
status/present     #2BB673   // 출석 (중립적 긍정)
status/late        #E8A53D   // 지각 (주의)
status/earlyLeave  #6C8AE4   // 조퇴
status/absent      #E5564E   // 결석/결과 (경고)

// Feedback
success            #2BB673
warning            #E8A53D
danger             #E5564E
info               #2E6BE6
```

규칙:
- **상태는 색만으로 전달 금지.** 항상 한글 라벨(출석/지각/조퇴/결석) + (선택) 아이콘 병기 — 색맹·키오스크 원거리 대응.
- 명도 대비 **WCAG AA** 이상(본문 4.5:1, 큰 텍스트 3:1).
- 다크모드는 v1 비범위(밝은 베이스 고정). 토큰은 시맨틱 네이밍이라 후일 다크 추가 용이.

## 2. 타이포그래피

- 글꼴: **Pretendard** (한글 가독성 표준). 숫자 강조엔 tabular figures.
- 스케일(학생앱/대시보드 기준 / 키오스크는 ×1.4~1.8):

```
display   32 / 700   // 키오스크 큰 안내("출석되었어요")
h1        24 / 700
h2        20 / 600
title     17 / 600
body      15 / 400
bodyStrong 15 / 600
caption   13 / 400   // 보조·타임스탬프
mono      15 / 500   // 학번·PIN·코드 (tabular)
```
- 키오스크 본문 최소 **24sp 이상**(원거리 가독, 접근성).

## 3. 스페이싱 & 형태

- 스페이싱 스케일(4 기반): `4 / 8 / 12 / 16 / 24 / 32 / 48`.
- 라운딩: `sm 8 · md 12 · lg 16 · pill 999`. 카드=md, 버튼=md~pill.
- 그림자: 최소(`elevation 1` 수준의 soft shadow). 미니멀 유지.
- 터치 타깃 ≥ 48×48dp(키오스크는 ≥ 64).

## 4. 컴포넌트 (핵심)

- **PrimaryButton** — 큰 CTA. 학생 "출석", 교사 "세션 시작". 로딩/비활성 상태 명확.
- **StatusChip** — 출결 상태 표시(색+라벨). 표·그리드 공용.
- **StudentTile** — 아바타(이니셜) + 이름 + 학번 + StatusChip. 대시보드 그리드/리스트.
- **RotatingQrCard** — 키오스크 회전 QR(잔여 시간 링 표시).
- **PinPad** — 키오스크 PIN 입력(특대, 오입력 피드백).
- **LiveCountHeader** — 실시간 출석 카운트 + 핑 펄스 인디케이터.
- **ExceptionRow** — 나이스 내보내기 미리보기 행(교시·상태·사유).
- **ConsentGate** — 미동의 학생 표시·차단 안내.
- **EmptyState / ErrorState / OfflineBanner(큐 동기화 대기)**.

## 5. "핑" 모션 & 피드백 (절제된 시그니처)

브랜드의 유일한 "놀이" 포인트. 과하지 않게.
- **핑 펄스:** 비컨 활성·실시간 수신 시 작은 동심원 펄스(브랜드 블루). 위치: LiveCountHeader, 키오스크 "수신 중" 표시.
- **출석 성공:** 짧은 스케일-인 체크 + 경량 햅틱 + (선택) "핑" 사운드 1회. 300ms 이내, 1회성.
- **회전 QR:** 5초 잔여를 원형 프로그레스로. 만료 직전 색 전환(주의).
- 모션 토큰: `fast 120ms / base 200ms / emphasized 300ms`, ease `cubic(0.2,0,0,1)`. 접근성: "동작 줄이기" 설정 시 펄스/사운드 비활성.

## 6. 접근성 체크리스트
- 명도 대비 AA, 상태는 색+텍스트, 터치 타깃 충족.
- 키오스크 특대 폰트·고대비, 단일 동작 흐름.
- 스크린리더 라벨(StatusChip="홍길동 지각" 식), 포커스 순서.
- "동작 줄이기"/사운드 off 존중.

## 7. 토큰 → 코드
이 토큰은 `app/lib/core/theme/`에 `AppColors`/`AppTypography`/`AppSpacing`/`AppTheme`로 구현한다(매직 값 금지, 항상 토큰 참조). 키오스크는 동일 토큰에 `scale` 배수만 적용.

## 8. 비범위(v1)
